# Jhoan Cevallos - Portafolio Personal

Bienvenido al repositorio de mi código fuente. Este sitio web es mi carta de presentación y un catálogo centralizado de mis proyectos de ingeniería de software. 

**Perfil Profesional**
Soy estudiante de Ingeniería de Software en la Universidad Estatal de Milagro (UNEMI). Mi interés principal radica en la construcción del lado del servidor, enfocándome en arquitecturas escalables, diseño eficiente de bases de datos y desarrollo de APIs.

**Stack Tecnológico y Herramientas**
* **Backend:** Python (FastAPI, Django)
* **Bases de Datos:** PostgreSQL, SQL Server, Oracle SQL
* **Arquitectura:** Diseño de microservicios, OOP, y sistemas relacionales
* **Frontend (Portafolio):** HTML5, CSS3 

**Estructura del Proyecto**
El código de este repositorio contiene la estructura estática del portafolio. Está diseñado para ser ligero, de carga rápida y fácilmente escalable para cuando necesite consumir datos de mis propios microservicios.
